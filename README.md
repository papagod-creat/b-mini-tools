# b-mini-tools 🧰

单文件 HTML 小工具集——**零依赖、零构建、数据不出浏览器**，双击即用，也可直接挂 GitHub Pages。

## 工具列表

| 工具 | 说明 |
|---|---|
| ⏱ 倒计时 | 分钟 + 秒设定，结束后标题栏闪烁提醒 |
| 📐 单位换算 | 公里/英里、公斤/磅、摄氏/华氏、MB/GB |
| 🔤 字符统计 | 中英混排计数：中文按字、英文按词 |

## 使用

```bash
# 方式一：直接打开
双击 tools.html

# 方式二：GitHub Pages
仓库 Settings → Pages → 选择 main 分支根目录
```

## 设计原则

- **单文件**：一个 HTML 包含全部 HTML/CSS/JS，方便拷贝部署
- **零依赖**：不引任何第三方库，离线可用
- **本地优先**：所有计算在浏览器完成，无网络请求、无埋点
